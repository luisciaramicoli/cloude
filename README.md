# Projetos de Cloud Computing

Este repositório contém os projetos desenvolvidos para a disciplina de Cloud (Computação em Nuvem) ministrada pelo professor @siriani.

## Catálogo de Filmes - Tom Hanks

O projeto principal atual encontra-se na pasta `catalogo-filmes-tmdb`. Trata-se de uma aplicação fullstack (Node.js, Express, MariaDB, React SPA) que consome a API do TMDB para listar os filmes do Tom Hanks, permitindo que os usuários criem contas isoladas para favoritar e comentar nos filmes.
